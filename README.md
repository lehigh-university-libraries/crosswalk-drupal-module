## INTRODUCTION

The Crosswalk module integrates with the crosswalk CLI tool to convert scholarly metadata between formats.

The primary use case for this module is:

- Rendering schema.org JSON-LD in your node view HTML
- Rendering citations for scholarly content

## REQUIREMENTS

crosswalk CLI binary in your web server's path
RDF mappings for the content you want to render using crosswalk OR manually creating a crosswalk profile for your content type(s)

## INSTALLATION

Install as you would normally install a contributed Drupal module.
See: https://www.drupal.org/node/895232 for further information.
